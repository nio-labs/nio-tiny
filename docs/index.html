Nio Tiny — Sub-300MB RAM 135M Sovereign Edge Fleets

Why should a Raspberry Pi Zero, a 512 MB IoT board, or an old netbook be locked out of agentic AI? Nio Tiny shrinks Lead routing, Web Scout grounding, Anti-Hallucination Guard, /teach memory, and --verify self-repair down to 135M parameters and ~250 MB active RAM.

3. Quickstart

# 1. Install nioxs
curl -fsSL https://raw.githubusercontent.com/nio-labs/nio-xs/main/install.sh | bash

# 2. Pull Tiny Meerkat (202 MB) or Tiny Orca (23 x 101 MB)
nioxs pull tiny-meerkat
nioxs pull tiny-orca

# 3. Run locally (~250 MB RAM)
nioxs tiny-meerkat "write a python function to check palindrome"
nioxs tiny-orca --retries 16 "write a python function to add two numbers"
